📘 Tutoriel : Historiques de version SharePoint & génération du rapport CSV
Guide pas-à-pas pour comprendre les versions, créer le rapport, puis l'analyser avec cette page.

1) Comprendre l'historique des versions SharePoint

SharePoint conserve des versions de vos documents pour permettre le suivi, la restauration et l'audit. Chaque nouvelle sauvegarde peut créer une version, ce qui consomme de l'espace. Paramètres clés :

  • Nombre de versions majeures / mineures (paramètres avancés de la bibliothèque).
  • Conservation (durées/stratégies, labels de rétention si utilisés).
  • Taille des versions : fichiers volumineux et modifications fréquentes peuvent faire exploser le stockage.
Astuce : Activer le mode automatique (si besoin, limitez le nombre de versions et nettoyez celles très anciennes si compatible avec vos exigences de conformité.)

2) Pré-requis pour exécuter les commandes PowerShell

  • Compte avec droits SharePoint Admin ou suffisants sur le site ciblé.
  • Module Microsoft.Online.SharePoint.PowerShell installé :
    Install-Module Microsoft.Online.SharePoint.PowerShell
  • Connexion préalable :
    Connect-SPOService -Url https://<tenant>-admin.sharepoint.com
    • 📘 Documentation Microsoft

3) Lancer le job de génération du rapport CSV

  • URL du site cible (-Identity) et URL de sortie du CSV (-ReportUrl) pointant vers une bibliothèque existante.

    • Créer le job d'export du Version Expiration Report :

    New-SPOSiteFileVersionExpirationReportJob -Identity "https://xxx.sharepoint.com/sites/xxx" \
-ReportUrl "https://xxx.sharepoint.com/sites/xxx/Documents%20partages/VersionReport.csv"
    📘 Documentation Microsoft

    4) Suivre la progression du job

    Get-SPOSiteFileVersionExpirationReportJobProgress -Identity "https://xxx.sharepoint.com/sites/xxx" \
-ReportUrl "https://xxx.sharepoint.com/sites/xxx/Documents%20partages/VersionReport.csv"
    • Le cmdlet retourne l'état (en cours/terminé) et des détails de progression si disponibles.
    • Une fois terminé, téléchargez VersionReport.csv.

    5) Analyser le CSV avec cette page

    Revenez sur l'onglet Analyse puis glissez-déposez le VersionReport.csv : la page calcule la taille totale, le nombre de versions, le ratio taille/plus grande version et le top par ancienneté.

    6) Champs CSV attendus

    Le parseur accepte des colonnes comme : DocId.Compact, DocId, FileUrl.Compact, FileUrl, Size, LastModifiedDate/ModifiedDate. Les colonnes manquantes sont gérées quand c'est possible, mais veillez à l'intégrité du fichier.

    7) Dépannage rapide

    • CSV vide : vérifiez vos droits et l'existence de la bibliothèque indiquée dans -ReportUrl.
    • Erreur de connexion : assurez-vous d'être connecté avec Connect-SPOService sur l'URL d'admin.
    • Entêtes inattendus : ouvrez le CSV et vérifiez les colonnes.

    Remplacez les URLs d'exemple (https://xxx...) par celles de votre tenant/site.
